JavaScript Q&A #04
What is Event Delegation in JavaScript?

Event delegation is a technique of using event bubbling to handle events at a higher level in the DOM tree rather than on individual elements.

// Attach listener to parent container
document.querySelector('#parent').addEventListener('click', (e) => {
  if (e.target.matches('.btn')) handleBtn();
});

CSS Concept Frequently Asked

What is the difference between Flexbox and CSS Grid?

Flexbox is designed for 1-dimensional layouts (either a row OR a column), whereas CSS Grid is built for 2-dimensional layouts (rows AND columns simultaneously).

/* Flexbox: One axis direction */
.flex-container { display: flex; flex-direction: row; }

/* CSS Grid: Two dimensional grid lines */
.grid-container { display: grid; grid-template-columns: 1fr 2fr; }

JS Concept Core Question

Explain the difference between `var`, `let`, and `const`.

var is function-scoped and hoisted, whereas let and const are block-scoped. const prevents re-assignment.

var x = 10; // Function/global scope
let y = 20; // Block scope (can re-assign)
const z = 30; // Block scope (cannot re-assign)
