# HTML Questions and Answers

## 📖 Description

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It provides the basic building blocks of every website by defining elements such as headings, paragraphs, images, links, tables, forms and more.

- **HTML Extension:** `.html`
- **Example File:** `index.html`

---

## 🚀 How to Run HTML?

Unlike programming languages, HTML does not require any compiler or runtime environment. Simply create an HTML file and open it using any modern web browser such as Google Chrome, Mozilla Firefox, Microsoft Edge or Safari.

### How to Create an HTML File:

1. Open any code editor (VS Code, Sublime Text, Notepad++, Webstorm, Cursor, etc.).
2. Create a new file named `index.html`.
3. Write your HTML code.
4. Save the file.
5. Double-click the file or open it with your preferred web browser.

## 🟡 Level 2: Easy (21 - 40)

> ### 21. What is the difference between `<div>` and `<span>`?
>
> `<div>` is a block-level element used to group larger sections of content, while `<span>` is an inline element used to group or style small pieces of text within a line.

> ### 22. What is the difference between `id` and `class` attributes?
>
> `id` is unique — it can only be used once per page and identifies a single element. `class` can be reused on multiple elements to apply the same styling or behavior.

> ### 23. What is the difference between inline, block, and inline-block elements?
>
> Block elements take the full width and start on a new line (e.g., `<div>`, `<p>`). Inline elements take only the space they need and do not start a new line (e.g., `<span>`, `<a>`). Inline-block is a hybrid — it behaves like an inline element but allows setting width and height.

> ### 24. What is the purpose of the `alt` attribute?
>
> The `alt` attribute provides alternative text for an image if it fails to load, and it improves accessibility for screen readers and SEO.

> ### 25. What is the difference between `<ol>` and `<ul>`?
>
> `<ol>` creates an ordered (numbered) list, while `<ul>` creates an unordered (bulleted) list.

> ### 26. What is the `target` attribute used for?
>
> The `target` attribute specifies where to open a linked document. For example, `target="_blank"` opens the link in a new tab.

> ### 27. What is the difference between `<head>` and `<header>`?
>
> `<head>` contains metadata about the document (title, links, meta tags), while `<header>` is a semantic element that represents introductory content or navigation at the top of a page or section.

> ### 28. What are void (self-closing) elements?
>
> Void elements are HTML elements that do not have closing tags and cannot contain content, such as `<br>`, `<img>`, `<input>`, `<hr>`, and `<meta>`.

> ### 29. What is the difference between `<b>` and `<strong>`?
>
> `<b>` makes text bold for visual purposes only, while `<strong>` indicates that the text is of strong importance and has semantic meaning.

> ### 30. What is the difference between `<i>` and `<em>`?
>
> `<i>` displays text in italics for visual purposes, while `<em>` emphasizes text with semantic meaning, which is typically rendered in italics as well.

> ### 31. What is the purpose of the `lang` attribute?
>
> The `lang` attribute specifies the language of the webpage content, which helps search engines and screen readers. Example: `<html lang="en">`.

> ### 32. How do you add a comment in HTML?
>
> Comments are added using `<!-- comment here -->`. They are not displayed in the browser.

> ### 33. What is the difference between `<section>` and `<article>`?
>
> `<section>` groups related content within a page, while `<article>` represents a self-contained composition that can stand alone, such as a blog post or news article.

> ### 34. What is the purpose of the `title` attribute?
>
> The `title` attribute provides additional information about an element and displays a tooltip when the user hovers over it.

> ### 35. What is a favicon and how do you add it?
>
> A favicon is a small icon displayed in the browser tab. It is added using `<link rel="icon" href="favicon.ico">` inside the `<head>`.

> ### 36. What is the difference between absolute and relative URLs?
>
> An absolute URL contains the full web address (e.g., `https://example.com/image.png`), while a relative URL points to a file relative to the current page (e.g., `images/image.png`).

> ### 37. What is the purpose of the `<meta>` tag?
>
> The `<meta>` tag provides metadata about the document, such as description, keywords, author, viewport settings, and character encoding.

> ### 38. What is the difference between `<small>` and the deprecated `<font>` tag?
>
> `<small>` is a semantic tag that slightly reduces font size and is valid in HTML5. `<font>` was used to change font size, color, and face, but it is deprecated and should not be used.

> ### 39. What is the difference between `<sub>` and `<sup>`?
>
> `<sub>` renders text as subscript (below the baseline), while `<sup>` renders text as superscript (above the baseline). Examples: H₂O and x².

> ### 40. What is the difference between `<hr>` and `<br>`?
>
> `<hr>` creates a horizontal rule (thematic break) between content, while `<br>` inserts a single line break within content.

## 🟠 Level 3: Medium (41 - 60)

> ### 41. What are the new features introduced in HTML5?
>
> HTML5 introduced semantic elements (`<header>`, `<footer>`, `<section>`, `<article>`, `<nav>`, `<aside>`), multimedia elements (`<audio>`, `<video>`), Canvas and SVG, form enhancements, local storage, geolocation, and drag-and-drop support.

> ### 42. What is the difference between HTML4 and HTML5?
>
> HTML5 supports semantic tags, multimedia without plugins, better form controls, and new APIs like Canvas, while HTML4 relied on `<div>`-based layouts and plugins like Flash for multimedia.

> ### 43. What are `data-*` attributes used for?
>
> `data-*` attributes allow developers to store custom data in HTML elements, which can be accessed later via JavaScript using `dataset`. Example: `<div data-user-id="123">`.

> ### 44. What is the difference between `<script>`, `<script async>`, and `<script defer>`?
>
> A normal `<script>` blocks parsing until it loads and executes. `async` downloads the script asynchronously and executes it as soon as it is ready. `defer` downloads the script asynchronously but executes it only after the HTML is fully parsed.

> ### 45. What is the difference between `<canvas>` and `<svg>`?
>
> `<canvas>` is a bitmap-based drawing surface that renders instantly and is better for animations and games. `<svg>` is vector-based, scalable, and better for graphics that need resolution independence and DOM access.

> ### 46. What is the difference between `GET` and `POST` methods in forms?
>
> `GET` appends form data to the URL, is visible, and has size limits — suitable for non-sensitive data. `POST` sends data in the request body, is more secure, and is used for sensitive or large amounts of data.

> ### 47. What is the purpose of the `<datalist>` element?
>
> `<datalist>` provides a list of predefined options for an `<input>` field, giving users autocomplete suggestions while still allowing them to type their own value.

> ### 48. What is the purpose of the `<template>` element?
>
> `<template>` holds HTML content that is not rendered on page load. It can be cloned and inserted into the document later using JavaScript.

> ### 49. What are the different types of `<input>` elements?
>
> Common input types include `text`, `password`, `email`, `number`, `date`, `checkbox`, `radio`, `file`, `submit`, `button`, `color`, `range`, and `search`.

> ### 50. What is the difference between `readonly` and `disabled` attributes?
>
> `readonly` prevents editing but still submits the value with the form. `disabled` prevents interaction entirely and does not submit the value.

> ### 51. What is the purpose of `<fieldset>` and `<legend>`?
>
> `<fieldset>` groups related form controls in a box, and `<legend>` provides a caption for that group, improving accessibility and organization.

> ### 52. What is the `pattern` attribute used for?
>
> The `pattern` attribute defines a regular expression that the input value must match for validation. Example: `<input pattern="[0-9]{5}">` for a 5-digit code.

> ### 53. What is the purpose of the `<details>` and `<summary>` elements?
>
> `<details>` creates an expandable/collapsible section, and `<summary>` provides the visible heading that users click to toggle it.

> ### 54. What is the purpose of the `<picture>` element?
>
> `<picture>` provides responsive images by letting developers specify multiple `<source>` elements with different `srcset` and `media` conditions, so the browser picks the appropriate image based on screen size and resolution.

> ### 55. What is the purpose of the `<output>` element?
>
> `<output>` displays the result of a calculation or user action, commonly used with JavaScript and forms. Example: showing a sum in a calculator.

> ### 56. What is the difference between `<blockquote>` and `<q>`?
>
> `<blockquote>` is used for long block-level quotations that are indented, while `<q>` is used for short inline quotations, and browsers typically add quotation marks automatically.

> ### 57. What is the purpose of the `<progress>` element?
>
> `<progress>` displays the progress of a task, such as a file download or form completion, using attributes like `value` and `max`.

> ### 58. What is the purpose of the `<meter>` element?
>
> `<meter>` displays a scalar measurement within a known range, such as disk usage or a rating, with attributes like `value`, `min`, `max`, `low`, `high`, and `optimum`.

> ### 59. What is the difference between `src` and `href` attributes?
>
> `src` is used to embed external resources directly into the document (e.g., `<img src>`, `<script src>`), while `href` is used to link to external resources or pages (e.g., `<a href>`, `<link href>`).

> ### 60. What is the purpose of the `charset` attribute?
>
> The `charset` attribute specifies the character encoding for the document. Example: `<meta charset="UTF-8">` ensures that all characters, including emojis and special symbols, display correctly.

## 🔴 Level 4: Hard (61 - 80)

> ### 61. What is the purpose of the `<noscript>` tag?
>
> `<noscript>` defines fallback content that renders only when JavaScript is disabled or unsupported in the browser.

> ### 62. What is the purpose of the `sandbox` attribute in `<iframe>`?
>
> The `sandbox` attribute applies restrictions to content inside an `<iframe>`, such as disabling scripts, forms, pop-ups, and plugin content. Example: `<iframe sandbox="allow-scripts">`.

> ### 63. What is the viewport meta tag and why is it important?
>
> `<meta name="viewport" content="width=device-width, initial-scale=1">` controls how a page is displayed on mobile devices and is essential for responsive web design.

> ### 64. What is the purpose of the `<base>` tag?
>
> `<base>` sets a base URL and target for all relative URLs in the document. Example: `<base href="https://example.com/">`.

> ### 65. What is the difference between `<address>`, `<cite>`, and `<blockquote>`?
>
> `<address>` provides contact information, `<cite>` references the title of a creative work (a book, article, etc.), and `<blockquote>` contains a long quotation.

> ### 66. What is the purpose of the `<mark>` element?
>
> `<mark>` highlights text that is relevant or marked for reference, typically rendered with a yellow background.

> ### 67. What is the purpose of the `<abbr>` element?
>
> `<abbr>` defines an abbreviation or acronym, and the `title` attribute can be used to show the full form on hover. Example: `<abbr title="HyperText Markup Language">HTML</abbr>`.

> ### 68. What is the purpose of the `<code>`, `<pre>`, and `<samp>` elements?
>
> `<code>` displays a piece of computer code in monospace font, `<pre>` preserves whitespace and line breaks (preformatted text), and `<samp>` represents sample output from a program.

> ### 69. What is reverse tabnabbing and how can you prevent it?
>
> Reverse tabnabbing is a phishing attack where a page opened via `target="_blank"` uses `window.opener` to redirect the original page. Prevent it by adding `rel="noopener noreferrer"` to links that use `_blank`.

> ### 70. What is the difference between `http-equiv` and `charset` in `<meta>` tags?
>
> `charset` directly specifies the document encoding (`<meta charset="UTF-8">`), while `http-equiv` simulates HTTP headers, such as `refresh` or `X-UA-Compatible`: `<meta http-equiv="refresh" content="5">`.

> ### 71. What are HTML entities and character references?
>
> HTML entities are special codes that represent reserved characters or symbols. Examples: `<` for `<`, `>` for `>`, `&` for `&`, and `&copy;` for ©.

> ### 72. What is the purpose of the `rel="noopener"` attribute?
>
> `rel="noopener"` prevents the opened page (`target="_blank"`) from accessing the original page via `window.opener`, improving security and performance.

> ### 73. What is the purpose of the `<optgroup>` element?
>
> `<optgroup>` groups related options inside a `<select>` dropdown, making long lists easier to read. Example: grouping countries by continent.

> ### 74. What are the key attributes of `<audio>` and `<video>` elements?
>
> Key attributes include `src`, `controls`, `autoplay`, `loop`, `muted`, `preload`, and `poster` (video only). `preload` accepts `auto`, `metadata`, or `none`.

> ### 75. What is the purpose of the `loading="lazy"` attribute?
>
> `loading="lazy"` tells the browser to defer loading an image or iframe until it is near the viewport, reducing initial page load time and bandwidth usage.

> ### 76. What is the purpose of the `crossorigin` attribute?
>
> The `crossorigin` attribute configures CORS (Cross-Origin Resource Sharing) requests for resources like `<img>`, `<script>`, and `<link>`. Values: `anonymous` and `use-credentials`.

> ### 77. What is the difference between `<kbd>` and `<var>`?
>
> `<kbd>` represents keyboard input (e.g., Ctrl+C), while `<var>` represents a variable in mathematical or programming context (e.g., `x`).

> ### 78. When should you use the `<figure>` element?
>
> `<figure>` should be used to wrap self-contained content like images, diagrams, or code snippets that are referenced in the main content, often paired with `<figcaption>` for a caption.

> ### 79. What is the difference between `<div>` and semantic layout elements?
>
> `<div>` has no semantic meaning and is used purely for styling/grouping, while semantic elements like `<header>`, `<nav>`, `<main>`, and `<footer>` describe the meaning of their content, improving accessibility and SEO.

> ### 80. What is the minimum required structure for a valid HTML5 document?
>
> A valid HTML5 document needs `<!DOCTYPE html>`, `<html lang="en">`, `<head>` with `<meta charset="UTF-8">` and a `<title>`, and a `<body>`.

## ⚫ Level 5: Expert (81 - 100)

> ### 81. What is the DOM and how does it relate to HTML?
>
> The DOM (Document Object Model) is a programming interface that represents the HTML document as a tree of objects. Browsers parse HTML to build the DOM, which JavaScript can then manipulate to dynamically change content, structure, and styles.

> ### 82. What is the Shadow DOM?
>
> The Shadow DOM is a web standard that encapsulates a DOM subtree and its styling inside a custom element, isolating it from the main document. It is a core part of Web Components.

> ### 83. What are Web Components?
>
> Web Components are a set of browser-native technologies — Custom Elements, Shadow DOM, HTML Templates, and ES Modules — that allow developers to create reusable, encapsulated custom HTML elements.

> ### 84. What is the purpose of the `<dialog>` element?
>
> `<dialog>` creates a native modal or non-modal dialog box. The `showModal()` and `close()` methods (via JavaScript) control its visibility, and it supports the `returnValue` property.

> ### 85. What is the `contenteditable` attribute?
>
> `contenteditable` makes an element's content editable directly in the browser. Example: `<div contenteditable="true">`. It is commonly used in rich-text editors.

> ### 86. What is the `<slot>` element used for?
>
> `<slot>` is used inside a Shadow DOM custom element to define insertion points where external light DOM content is rendered.

> ### 87. What are microdata and JSON-LD?
>
> Microdata and JSON-LD are ways to add machine-readable structured data to HTML for SEO. JSON-LD (`<script type="application/ld+json">`) is recommended by Google and used for knowledge panels, rich results, and schema markup.

> ### 88. What is the purpose of the `<portal>` element?
>
> `<portal>` is an experimental element that enables seamless navigation by embedding another page and allowing instant transition to it, unlike `<iframe>` which is embedded inline.

> ### 89. What is the `decoding` attribute used for?
>
> `decoding` controls how the browser decodes images. `sync` decodes synchronously, `async` decodes in the background, and `auto` lets the browser decide. `async` is recommended for most images.

> ### 90. What is the `fetchpriority` attribute?
>
> `fetchpriority` gives a hint to the browser about the relative priority of a resource. Values are `high`, `low`, and `auto`. Example: `<img fetchpriority="high">` for LCP (Largest Contentful Paint) images.

> ### 91. What is the `referrerpolicy` attribute?
>
> `referrerpolicy` controls how much referrer information is sent when a request is made. Values include `no-referrer`, `origin`, `same-origin`, and `strict-origin-when-cross-origin`.

> ### 92. What is the critical rendering path?
>
> The critical rendering path is the sequence of steps the browser takes to render a page: parsing HTML to build the DOM, parsing CSS to build the CSSOM, creating the render tree, computing layout, and painting. Optimizing it improves page load performance.

> ### 93. What is the difference between `preload`, `prefetch`, and `preconnect`?
>
> `preload` loads a resource that is critical for the current page immediately. `prefetch` loads a resource needed for the next page in the background during idle time. `preconnect` establishes an early connection (DNS, TCP, TLS) to an origin.

> ### 94. How does HTML5 handle offline web applications?
>
> HTML5 introduced the Application Cache (AppCache) for offline support, but it was deprecated. It was replaced by Service Workers and the Cache API, which give developers full control over caching and offline behavior.

> ### 95. What is the purpose of the Web App Manifest?
>
> The Web App Manifest (`<link rel="manifest" href="manifest.json">`) is a JSON file that defines metadata for a PWA (Progressive Web App), such as name, icons, start URL, display mode, and theme color.

> ### 96. What is the purpose of the `spellcheck` and `translate` attributes?
>
> `spellcheck` enables or disables spell-checking in editable elements, and `translate` specifies whether the element's content should be translated when the page is localized.

> ### 97. What are `aria-*` attributes and how do they relate to HTML?
>
> ARIA (Accessible Rich Internet Applications) attributes, such as `aria-label`, `aria-hidden`, and `role`, enhance accessibility for screen readers when native HTML semantics are insufficient.

> ### 98. What is the HTML Living Standard?
>
> The HTML Living Standard is the continuously updated specification maintained by WHATWG. It replaces the older versioned HTML5 spec and is the current authoritative standard for HTML.

> ### 99. What are the accessibility best practices for HTML?
>
> Use semantic elements, proper heading hierarchy, `alt` text for images, labels for form controls, sufficient color contrast, keyboard navigation, the `lang` attribute, and ARIA only when needed.

> ### 100. How do you optimize HTML for SEO?
>
> Use semantic HTML, one `<h1>` per page, descriptive `<title>` and `<meta>` tags, proper heading hierarchy, `alt` attributes, internal linking, canonical URLs, structured data (JSON-LD), and fast, mobile-friendly page performance.
