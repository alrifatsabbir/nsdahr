# HTML Questions and Answers

## 📖 Description

HTML (HyperText Markup Language) is the standard markup language used to create and structure web pages. It provides the basic building blocks of every website by defining elements such as headings, paragraphs, images, links, tables, forms, and more.

- **HTML Extension:** `.html`
- **Example File:** `index.html`

---

## 🚀 How to Run HTML?

Unlike programming languages, HTML does not require any compiler or runtime environment. Simply create an HTML file and open it using any modern web browser such as Google Chrome, Mozilla Firefox, Microsoft Edge, or Safari.

### How to Create an HTML File:

1. Open any code editor (VS Code, Sublime Text, Notepad++, etc.).
2. Create a new file named `index.html`.
3. Write your HTML code.
4. Save the file.
5. Double-click the file or open it with your preferred web browser.

## ❓ Questions with Answers

> ### 1. What is HTML?
>
> HTML (HyperText Markup Language) is the standard markup language used to create the structure of web pages.

> ### 2. What does HTML stand for?
>
> HyperText Markup Language.

> ### 3. What is the extension of an HTML file?
>
> `.html`

> ### 4. What is the purpose of the `<!DOCTYPE html>` declaration?
>
> It tells the browser that the document is an HTML5 document.

> ### 5. Which tag is the root element of an HTML document?
>
> The `<html>` tag.

> ### 6. Which tag contains metadata about the webpage?
>
> The `<head>` tag.

> ### 7. Which tag contains the visible content of a webpage?
>
> The `<body>` tag.

> ### 8. Which tag is used to create the largest heading?
>
> `<h1>`

> ### 9. Which tag is used to create a paragraph?
>
> `<p>`

> ### 10. Which tag is used to create a hyperlink?
>
> `<a>`

> ### 11. Which attribute specifies the destination of a link?
>
> The `href` attribute.

> ### 12. Which tag is used to display an image?
>
> `<img>`

> ### 13. Which attribute specifies the image source?
>
> The `src` attribute.

> ### 14. Which tag is used to create an unordered list?
>
> `<ul>`

> ### 15. Which tag is used to create an ordered list?
>
> `<ol>`

> ### 16. Which tag is used to create a table row?
>
> `<tr>`

> ### 17. Which tag is used to create a form?
>
> `<form>`

> ### 18. Which tag creates a text input field?
>
> `<input type="text">`

> ### 19. Which tag is used to insert a line break?
>
> `<br>`

> ### 20. What is the purpose of semantic HTML?
>
> Semantic HTML uses meaningful elements that improve accessibility, readability, and SEO.
