# NSDAHR

### NSDA Helpful Resources

A modern documentation website for **HTML**, **CSS**, and **JavaScript** Questions & Answers, designed especially for NSDA students and beginner web developers.

[Live Demo](https://alrifatsabbir.github.io/nsdahr/) • [Report Bug](../../issues) • [Request Feature](../../issues)

## 📖 About

**NSDAHR (NSDA Helpful Resources)** is a lightweight documentation platform that organizes learning resources into clean, searchable, and easy-to-read documentation.

Instead of browsing dozens of websites, students can quickly access categorized **Questions & Answers**, **code examples**, and **study materials** for core web technologies.

Currently includes:

- 🌐 HTML Q&A
- 🎨 CSS Q&A
- ⚡ JavaScript Q&A

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/AlRifatSabbir/nsdahr.git
```

Go to the project directory

```bash
cd nsdahr
```

Open with a local server

Example:

```bash
python -m http.server
```

or

```bash
npx serve
```
